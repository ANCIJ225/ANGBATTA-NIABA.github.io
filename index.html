Bienvenue sur le Gestionnaire Académique

Ce projet est un système de gestion académique développé en Java avec Spring Boot. Il permet de gérer les étudiants, les cours, les notes et de générer des bulletins.

Fonctionnalités

  • Ajouter, modifier et supprimer des étudiants
  • Ajouter, modifier et supprimer des cours
  • Ajouter, modifier et supprimer des notes
  • Générer des bulletins pour les étudiants
  • Promouvoir les étudiants
  • Lister tous les éléments
  • Calculer des statistiques

Comment lancer l'application

1. Clonez le dépôt : git clone https://github.com/ancij/gestionnaire-academique-angbatta.git

2. Naviguez dans le dossier : cd gestionnaire-academique-angbatta

3. Lancez avec Maven : mvn spring-boot:run

4. Ouvrez http://localhost:8080 dans votre navigateur

Technologies utilisées

  • Java 11
  • Spring Boot
  • Thymeleaf
  • Maven
